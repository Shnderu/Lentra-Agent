# CORE IMMUTABILITY RULE (STRICT)

## ABSOLUTE RULE

It is STRICTLY FORBIDDEN to create new directories inside core/ without explicit manual approval.

Allowed actions:
- modify existing core modules
- extend existing logic
- refactor inside existing boundaries

Forbidden actions:
- core/new_module/
- core/experimental/
- core/v2/
- splitting domains into parallel implementations

## ENFORCEMENT PRINCIPLE

If a feature does not fit existing core structure:
→ It must be integrated into existing module
→ NOT create a new module

## ARCHITECTURAL LAW

Core is a SINGLE GRAPH, not a collection of independent services.

Violation = architectural corruption.
